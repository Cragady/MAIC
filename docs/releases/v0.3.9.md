# v0.3.9 (2026-10-03)

Artifacts served by MAIC, every leave case defined, and colored status.

## Fixed

* Two sessions created in the same second could get the same id, and the second was refused the first one's lock.

## New

* **Artifacts on maic-server.** `maic artifact add DIR`, `maic artifact list`, `maic artifact open ID` (a one-time login link; the browser stays logged in for 12 hours). Pages live under `/a/`, always sandboxed (opaque origin, scripts only from their own files and the vendored Vue, network only to their own data), with `data/NAME.json` saved beside them through revisions (a stale write gets 409). See `docs/artifacts.md`, including the security model.
* **`maic artifact allow-insecure ID`**, after typing `allow insecure`, lets one artifact build code at runtime (Vue's template compiler); audited on every load and shown in `maic artifact list`.
* **Vue 3.5.43 vendored** with its license, provenance and a verify script.
* **Every leave case defined.** A task follows its own case, with `leave.task.after` (default park); without the daemon a second window on a session is refused (one engine per transcript); remote flags only tighten. `ask` is allowed at quit. The leave audit on every test run reads 0 UNDEFINED.
* **Metered models ask first.** Anthropic and Claude Code count as metered; the checker panel asks before a paid judge on another account (`checkers.ask_before_metered`).
* **Notifications for agents:** `maic artifact watch ID` prints one line per submit, side prompt, After Prompt or split request (never the content); `tools/agent-kit/artifact-watch.sh` does the same for agents outside MAIC; `maic channel` pushes the same events into a Claude Code session through Channels (research preview: `claude --dangerously-load-development-channels server:maic`). Events land on notification protocols the user approves (`maic artifact protocol ID`), identified and verified by hash. See `docs/agent-kit.md`.
* **Colored `maic status`** by process state, with a `GPU` tag; `--text-base` prints plain tab-separated records on status, gpu, models and daemon status; `NO_COLOR` and piped output give plain text.
