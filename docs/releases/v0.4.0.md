# v0.4.0 (2026-10-03)

MAIC is now **maid**: an agent runner. *Mica's AI Decisions*, or *Micaiah's Agentic Interface Delta*. Blame trans-fairy: it made MAIC transition to MAID.

## Changed

* Every live name moves: the commands (`maid`, `maid-server`, `maid-relay`, `maid-diction`, `maid-workflow-edit` and the rest), `~/.config/maid`, `~/.local/state/maid`, the runtime directory, project `.maid/` folders, `MAID.md`, `MAID_*` variables, `maid.nvim`, the protocol's extension namespace (`maid.`), the artifact files and headers, the systemd units in `contrib/systemd/`, and the Lua API.
* Not renamed: past release notes and transcripts, git history, the ComfyUI custom nodes and node types (saved workflows find them by name), the GitHub URL, `cai`, `trans-fairy`, and the `"maic"` key cai writes into converted records.
* The relay's encryption labels change (`maid-tunnel-v1`, `MAID1`): a paired phone reloads the web client; pairings themselves are kept.

## Moving your setup

Run `scripts/migrate-to-maid.sh` (a dry run by default). With `--apply` it moves directories only (config, state, runtime, each trusted project's `.maic/`) and never opens, edits or deletes a file; it prints everything else for you to do: `MAIC.md` renames, lines in your own config that still say maic, old `~/bin/maic*` links, systemd units, the `~/dev2/MAIC` folder move with `git worktree repair`, and your nvim plugin spec. It refuses to apply while a maic process runs: stop the daemon and any sessions first.
