# v0.4.1 (2026-10-03)

## Added

* **`maid liaison`** (`send`, `approve`, `status`): hands a turn to a session the daemon holds and returns the reply on the same connection, without taking focus from a window attached to it. The key stays in the daemon. [daemon.md](../daemon.md#the-liaison)
* **`:usage`**: tokens (cache hit and miss, output), estimated spend, `max_concurrent` use and rate-limit state per model, whether each provider's key variable is set (never its value), the session total, and the cost estimates of all sessions.
* **`:status`** says much more: session, transcript, model and the model that answered, thinking, context, turns, cost, mode, harness, workspace trust, daemon, background tasks.

## Fixed

* A turn is priced, and counted, as the model that answered it (a Pro request served by Flash costs Flash's price).
* An installed maid reads the service files it shipped with, never the source checkout (after the rename, `v0.3.10` stopped on `${MAID_VENDOR}` from the checkout).
* A service file that doesn't load is skipped with a warning; the other services, `maid up`, `:cd` and the rest keep working.
* `:cd` during a turn says it waits instead of doing nothing; Tab after `:cd` completes directories (relative, absolute, `~/`).
* The editor is in normal mode after an Alt+Enter send, whatever the terminal's timing.
* The half-cap concurrency notice is told once while a queue drains; the diction test no longer fails when `FORCE_COLOR` is set.
