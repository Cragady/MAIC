# v0.3.6 (2026-10-02)

nvim is MAIC's interface. This completes roadmap item 1.

## New

* **`:Maic` opens the nvim interface** on `maic --rpc`: a conversation buffer with markdown highlighting, an input buffer, and a winbar with model, mode and state. `<CR>` (normal) or `<M-CR>` (insert) sends; `/cmd` runs an engine command, `!cmd` a shell command, and a message sent mid-turn steers the turn.
* Floats for approvals (`y`, `n`, `N`, `a`, `t`; `e` opens the file, `d` diffs a write), questions and the pause menu. Long tool output and reasoning fold closed when done.
* Steering keys `<C-c>`, `<C-s>`, `<C-q>` and `:MaicSteer`, in maic.nvim's defaults table, never overwriting a mapping you have; `:checkhealth maic` reports them.
* `:MaicTerminal` or `ui = "terminal"` keeps the terminal TUI. `maic --ui nvim` starts nvim with your config and the interface.
* **Event filtering.** A client lists the delta types it does not want in `maic.hello`'s `exclude`; the next event after a skip carries `maic.filtered_from`, and `maic protocol check` accepts exactly the gaps a filter explains. Sequence numbers stay the session's, so resuming works across filters and devices.

## Fixed

* A llama-server stream that ends on a bare `proxy error` line (the model unloaded mid-reply) is now an error, not a short complete reply.
* The audit trail's hold says why it starts the judge, ends its "starting..." line, and leaves a judge port held by another server to the audit.
* `maic -p` no longer receives live tool output it never printed.

## Known gaps

* A resumed session opens empty in the nvim interface until history loading lands; `:MaicTerminal` shows the scrollback.
