# v0.3.2 (2026-10-01)

Instruction discovery, approvals for imports from your own instruction files, a sandbox that works on NixOS, a security fix to how MAIC tells local providers from remote ones, and two smaller fixes.

## Security

* **A provider could pass for local by its URL's text.** MAIC called a provider local when its `base_url` merely contained `://127.`, `://localhost` or `://[::1]` anywhere, so `https://example.com/x?y=://127.0.0.1`, `http://127.0.0.1.attacker.example/` or `http://127.0.0.1@evil.example/` counted as local. That hid the REMOTE warning and let rules meant for local models (a local preset's subagents, diction's local backend) send prompts and files off the machine. The URL is now parsed (scheme, userinfo, host, port) and a provider is local only when its host is exactly a loopback address (`127.0.0.0/8` as a dotted quad, `::1`, `localhost`) or it is a unix socket. `maic-server` and `maic-relay` judge their listen address by the same rule ([settings.md](../settings.md)).
* **The Nix daemon socket is out of the sandbox's reach.** `/nix/var/nix/daemon-socket` is masked: through it a sandboxed command could have built any derivation, including fixed-output ones that fetch from the network.

## New

* **Instruction discovery** ([instructions.md](../instructions.md)). `CLAUDE.md`, `AGENTS.md` and `MAIC.md` are all read, lowest priority first, from `/etc/maic/` (a system slot, empty by default), `~/.config/maic/` and each trusted directory from the project root down to the workspace; later files take precedence, and the model is told so. `MAIC.local.md` and the like follow their directory's shared files. `@path` imports another file (four hops, relative to the importing file, never from code). Reading a file in a subdirectory attaches its instruction files once per session. The global `instructions` table sets the names (`files`), `read = "highest"`, `local_files`, `imports.depth` and `extra_dirs`; a project cannot set any of them. The page compares this with Claude Code and opencode and gives the reasons for each default.
* **Imports from your own files, with your approval.** An `@path` in `~/.config/maic/` or `/etc/maic/` may import a file from outside your trusted directories once you approve it. MAIC asks once (the TUI's confirm modal; headless, a notice naming `maic trust imports --approve`), showing the file, its size and what approving means: standing instructions for every agent in every project, sent to whichever provider a session uses, paid for in tokens by every session, and changeable by anything that can write the file. Approvals are kept with the file's SHA-256 in `<state>/trust-imports.json`; a changed file is asked about again under your trust tier. `maic trust imports` lists them, `--remove PATH` forgets one. The agent can never approve one, and an approved file is protected from the agent's writes ([instructions.md](../instructions.md#imports-from-your-own-files)).
* **The sandbox works on NixOS.** After `/run` is emptied, exactly `/run/current-system`, `/run/booted-system`, `/run/wrappers`, `/run/opengl-driver` and `/run/opengl-driver-32` are bound back read-only when they exist, with any socket inside them masked. Setuid wrappers stay inert: the sandbox runs everything with `no_new_privs` ([harness.md](../harness.md#layers), rule 6).

## Fixed

* **Ctrl-D and Ctrl-U scrolled the wrong way** from the input's normal mode. Ctrl-D now scrolls down and Ctrl-U up, as in vim and in the conversation window.
* **`maic nvim setup llama-vim` refused when a config file merely mentioned llama.vim.** Only lazy.nvim's resolved spec decides now; a comment or note is a warning (`init.lua mentions llama.vim; it is not loaded as a plugin, continuing`).

## What you will notice

* **Trusted directories may be asked about once more.** A directory's trust now covers every instruction file it contributes: `CLAUDE.md`, local files, instruction files in its subdirectories and what they import inside it. A directory holding any of these is asked about again the first time; answer as before.
* **`CLAUDE.md` now counts.** A directory holding a `CLAUDE.md` is a project directory (asked about before it is used), its `CLAUDE.md` reaches the model, and with `sessions_home = "auto"` its transcripts go under the project's home.
* **`instruction_files` is gone.** Set `instructions.files` in your global settings instead; a file that still sets the old key gets a warning.
