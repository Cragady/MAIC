# v0.3.0-beta.1 (2026-10-01)

A minor-version jump: a second vendored engine, three new subsystems, renames that change behaviour, and a security fix. Everything below landed together; this page is the one place that lists it.

## Security

* **Project settings could run code.** Up to v0.2.0-beta.12, starting MAIC in a directory evaluated that directory's `.maic/settings.lua` with full Lua (`os.execute` included) and applied its `permission.allow` entries, before any harness check. Now a directory is read only after you trust it (see Trust below), and a directory trusted *sandboxed* runs its Lua in a child process that cannot reach the system. If you ran an older MAIC inside a repository you did not write, look at that repository's `.maic/` files.
* **Allow entries approved chained commands.** `maic path*` also approved `maic path && anything`. Allow entries, helper rules and a session's "always" now match a single plain command only; deny and ask entries now match every command inside a chain.

## You will notice

* **A trust prompt** the first time MAIC starts in each project directory: `t` trust fully, `s` trust sandboxed, `n` not now, `v` never. Your own files under `~/.config/maic` are trusted. Strictness tiers decide when you are asked again ([harness.md](../harness.md), [settings.md](../settings.md)).
* **`delegate` is now `task`**, profiles are **agents** (`profiles` is still read), the built-in agents are `build`, `plan`, `general` and `explore` (the old names still work in settings and `task` calls), and `title_model` is now `small_model` (still read). A live `delegate` tool call is no longer accepted.
* **The reviewer** for the Anthropic presets defaults to the cheapest adequate model (Haiku) rather than Sonnet; local models review themselves.
* **`cai` is MAIC's port** of cai-tools, every tool with its name and contract; the old uv-installed `cai` is retired.
* **diction** lives in MAIC: `maic diction`, whisper.cpp for speech, and by default Haiku through the `claude` CLI on your own login, as before. Its config moves to `~/.config/maic/diction.lua` (the old `config.toml` is still read, with a notice; `diction migrate-config` converts it).
* **`:cd` changes the session's directory** (`:path` keeps showing places).
* **`cai reflow FILE` refuses a MAIC session**, as it refuses a Claude projects file; `--rewrite-session` is the operator's way through.
* **The test gate stays off the network** unless `MAIC_NETWORK_TESTS=1`.

## New

* **Agents and model tiers:** the `task` tool, agent roles, preset tiers with `limited`, `subagents`, `on_limit`, usage-limit fallback for subagents and the reviewer, `small_model`, `reviewer_budget_tokens`.
* **All of cai-tools** under `tools/cai`, callable as `cai` or `maic cai`, with MAIC sessions behind the same contracts; `trans-fairy-write` backs up first and gains `restore` and `list-backups`.
* **maic.nvim:** the plugin, MAIC connecting to its host nvim, `:e` and diffs in the host, theme following, User autocmds, `:MaicInterrupt`, the `diagnostics` tool, `:checkhealth maic`, `maic nvim keymaps`, `maic nvim setup llama-vim`, and `--bare` for MAIC with nothing from nvim.
* **Themes:** `:theme`, shipped gruvbox and mono themes, `:theme nvim:NAME` imports a colorscheme.
* **Model catalog:** `maic models` lists, installs, verifies and removes models by name, with briefs and VRAM estimates; the `llamacpp-fim` completion server for llama.vim.
* **Sessions:** `:init` moves a session into its project home when it worked there; `maic sessions rehome` takes several sessions and moves subagent sessions only on request.
* **lazy-lock tracking:** `maic lazy-lock` and a notice when nvim's `lazy-lock.json` no longer matches the recorded hash.
* **Lua levels** for settings files (`full`, `sandbox`, `restricted`) and [limits.md](../limits.md), the list of every known limit.

The full record is the Done list in [roadmap.md](../roadmap.md).
