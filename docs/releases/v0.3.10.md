# v0.3.10 (2026-10-03)

Ready for real DeepSeek use: safer API calls, cost estimates, and readable help.

## New

* **Retries that can't get an account banned.** Every API provider backs off exponentially with full jitter (1 s base, 60 s cap), honours `Retry-After`, never retries 400, 401, 402 or 403, holds every request to a provider account after a 429, and opens a circuit breaker for 60 s after five 429s within a minute, saying so plainly.
* **A concurrency cap per provider** (`options.max_concurrent`): DeepSeek ships a third of its own limits (833 Flash, 166 V4 Pro); requests beyond it queue, and passing half the cap warns once.
* **`GET /models`** read at the first use of a provider that sets `read_models` (on for DeepSeek), with short timeouts and no retry; the window, output limit and thinking levels come from it, with the saved copy and the catalog as fallbacks. `maic models refresh` reads it again; `maic models` lists API models.
* **Cost estimates**: every priced call is costed (cache hit, cache miss, output; peak or off-peak), summed per session (subagents and background tasks included) and shown in the status line and `:status`; a running average across sessions stays local in `<state>/costs.json`.
* **Help topics laid out like man pages**: NAME, SYNOPSIS (the command's own usage block), DESCRIPTION, FILES, SEE ALSO, styled in a terminal and plain under `--text-base`, `NO_COLOR` or a pipe.

## Fixed

* Helper programs MAIC runs (nvidia-smi, sha256sum, docker, the vendor builds, clipboard tools and others) start without API keys in their environment.
* `maic help artifact` no longer suggests that `allow-insecure` permits inline scripts.
