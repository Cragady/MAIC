# v0.4.4 (2026-10-03)

## Added

* **`approvals_timeout`** (seconds, default 300; 0 for none): an approval or question nobody answers no longer holds a session forever. On expiry an approval is denied and a question answered empty, both marked `timed_out` with `by` `timeout`; the model is told it was not answered and to carry on. A project settings layer can only lower it (0 or a raise is a widening, and a broken layer naming it is refused).
