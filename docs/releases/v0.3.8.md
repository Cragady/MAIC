# v0.3.8 (2026-10-03)

Everything merged since v0.3.7: background work, API models, a judging panel and self-describing sessions.

## New

* **API models, DeepSeek built in.** Any OpenAI-compatible API is a few lines of `settings.lua` (`providers.NAME` with `base_url` and `api_key_env`). DeepSeek ships as `deepseek-pro`, `deepseek-flash` and `-nothink` variants: reasoning is kept and replayed as DeepSeek requires, an empty balance is never retried, cut-off tool calls are never run, and a silent model re-route is reported. Keys come only from the environment and never reach sandboxed commands; providers are global-only.
* **Claude Code as a model and as the agent.** The `claude-cli` provider runs Claude Code text-only, or as the agent on MAIC's own tools over a local MCP socket (`maic mcp-bridge`), with MAIC as the only judge.
* **A checker panel** for the smart harness: `checkers = "dual-9b"` (Qwen3.5 9B first, Claude Haiku 4.5 on escalation) or `dual-4b`, with `primary`, `escalate` and `both` policies; every verdict is recorded with `judged_by`.
* **Several sessions at once**: `:new`, `:switch`, `:fork`, `:bg`, `:park`, `:stop`, in the TUI and maic.nvim, running in parallel.
* **The daemon**: `maic daemon start|stop|status|run|unit`, so sessions outlive the window that started them. Nothing is installed or enabled unless you run `maic daemon unit install` and enable it yourself.
* **Background tasks**: `task` with `background: true` runs a subagent as its own session beside your turn; its report comes back to the parent. `max_tasks` limits how many run at once.
* **The `leave` table**: what switching away and quitting do to idle and working sessions, every case defined; `--bg`, `--park` and `--stop` override one leave.
* **History**: a resumed session shows its last exchanges in the nvim interface, with older ones loaded on request (`:MaicOlder`).
* **Self-describing sessions**: transcripts carry an epoch, numbers that continue across restarts, and the shape of every record type they use, so they can be read without MAIC's source.

## Changed

* `session_leave` is replaced by `leave`; a leftover `session_leave` line is an error that names the replacement.
