# v0.3.7 (2026-10-02)

New defaults: the dumb harness and auto mode, so neither needs a flag.

## Changed

* **`harness = "dumb"`, `mode = "auto"` and `dumb_auto_ok = true` are the defaults.** The smart harness is slow on local models; set `harness = "smart"` to have it back, `dumb_auto_ok = false` for the warning.
* **Auto waits at start where a directory is not fully trusted**: untrusted, sandboxed or restricted Lua, or a plain directory with nothing to trust (`$HOME`, `/`). The session says so once; `:mode auto` turns it on. `--mode auto`, or a local client asking for auto, starts in auto anywhere.
* **A remote client cannot create a session in auto** without the step-up check, the same rule as switching to auto. maic-server forwards a mode only when the request names one, and the web client leaves auto out.
* The model catalog's Qwen3.5 9B entries record that a system-prompt rule is ignored on turns that call a tool (measured 2026-10-02, not yet measured on other families).
