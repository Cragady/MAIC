# v0.4.3 (2026-10-03)

## Added

* **Voices.** `maid liaison send --as NAME` names who is speaking; owner names (micaiah, user, local, system and the like) are refused, and the name is fixed for the connection. Such a turn is recorded with origin `liaison` and its sender, shown in the window as `◆ NAME (liaison)`, read back as `[liaison:NAME]`, and the model is told by maid itself who it is from, with the sender's text quoted so it cannot fake that line. A `liaison` style role and per-name backgrounds: `voices = { NAME = { bg = "..." } }`.
* `scripts/check-quiet.sh`: the gate with a short verdict, for agents.

## Fixed

* `maid -r ID` resumes that session or says why not: from a current directory that no longer exists it resumes in the session's own workspace with a notice; a resume through the daemon shows the session's recent history instead of an empty view that looked like a new session.
* A user-run `!cmd` or `:lua` says when the agent will see its result ("result added; the agent sees it with your next message" or "result queued ..."), and a result arriving as a turn closes now starts a turn of its own instead of waiting for the next message.
* A window attached to the daemon shows another client's turns at once, not after a key press.
