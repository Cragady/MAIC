# v0.4.5 (2026-10-03)

## Added

* **Unattended turns.** `approvals_unattended = "deny"` (per session) or `maid liaison send --unattended` (per turn): every approval and question is answered at once, the model told plainly that approvals are off in this turn by design, and nothing trips. They count toward `unattended_denials_limit` (default 5), which ends the turn quietly. A task inherits the flag; a project layer can only tighten either setting.

## Fixed

* A timed-out denial is recorded as judged by `timeout`, not by the user.
